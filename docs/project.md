# 项目提取说明

本项目从已有 Go 行情服务中提取 K 线接口和四种数据源适配器，改为独立入口、独立配置和独立构建。保留原接口的 JSON 业务码、OHLCV 字段、WebSocket 消息及美股时段参数。

## 包含

- TradingView 历史、实时和交易对搜索。
- Binance / Tencent / BiQuote 多源历史和实时路由。
- Hub 共享订阅、延迟回收、初始化同步和取消处理。
- 已有 TradingView 历史限时、有限重试、并发控制，以及实时退避和握手错误日志。
- 新的进程退出清理、WS 连接/订阅上限、来源控制和健康检查。
- Docker/Compose、systemd、Nginx、Linux 双架构打包、GitHub CI 与标签 Release 工作流。

## 未包含

原服务的数据库和迁移、账户、登录、交易策略、下单、机器人、通知、私有部署配置、旧二进制、日志、备份和 Git 历史。项目构建不读取原仓库或本机目录。

## 验证范围

`go test -race ./...` 使用本地可控上游验证协议、重试、取消、并发去重、连接回收、时段隔离、REST 业务码、CORS、订阅/连接限制和关闭行为。它不证明外部行情提供方一直可用。

发布准备时还应执行 `go vet ./...`、`go mod verify`、本机二进制启动检查、Linux amd64/arm64 构建和示例 Nginx 配置检查。Docker 构建与启动由 CI 单独检查；本机没有可用 Docker daemon 时不能宣称容器运行已通过。


## 2026-11-13 发布准备验证

- Go 1.25.6 全量 race 测试连续三轮通过，22 个顶层测试及参数化子项；`go vet`、格式检查、`go mod verify` 通过。
- Linux amd64 / arm64 静态二进制及打包校验文件构建完成；本机可执行程序成功启动。
- Nginx 示例语法、实际代理存活检查及 Compose 配置校验通过。本机 Docker daemon 未启动，容器实际构建/启动由 GitHub CI 检查。
- 本机 TradingView 连接超时，真实行情 smoke 失败情况如实保存在记录中。另在可连接上游的服务器启动独立临时进程，5 组真实历史请求、搜索以及6次实时订阅全部通过；未修改原有线上服务，预演进程和临时文件已清理。
